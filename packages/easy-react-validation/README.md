# @easingreact/easy-react-validation

A simple, flexible React validation utility that allows developers to manage their own state and components while providing prop-based validation and a centralized `validate()` method.

## ✨ Features

- ✅ Use **any form field** (MUI, Ant Design, native inputs, etc.)
- ✅ Add validation props like `required`, `minLength`, `maxLength`, `pattern`
- ✅ Centralized `validate()` method via a form ref
- ✅ No need to manage complex validation schemas

---

## 🚀 Install

```bash
pnpm add @easingreact/easy-react-validation
